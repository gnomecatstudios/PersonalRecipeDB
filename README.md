# PersonalRecipeDB

A searchable personal recipe website for GitHub Pages.

## Website

https://gnomecatstudios.github.io/PersonalRecipeDB/

## Add recipes

Add recipe Markdown files inside `recipes/`, then add each recipe to `recipes/index.json`. Use `recipes/RECIPE-TEMPLATE.md` as the standard format.

## Enable GitHub Pages

Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main**, choose **/(root)**, and save.

The included `qr-code.svg` points to the website address above.
